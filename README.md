# Organizador de Arquivos

Este projeto foi criado para resolver um problema do dia a dia: eu tinha muitos arquivos misturados na pasta de Downloads e precisava organizá-los de forma mais rápida.

O programa identifica o tipo de cada arquivo e copia ele para uma pasta correspondente, como `PDFs`, `Imagens` e `Compactados`. Arquivos de outros tipos são enviados para a pasta `Outros`.

Além de resolver esse problema, este projeto foi uma boa forma de treinar Python e praticar conceitos como caminhos de arquivos, dicionários, repetição, condições e cópia de arquivos.

## Como usar

1. Abra o arquivo `organizador.py`.
2. Altere os caminhos da pasta de origem e da pasta de destino.
3. Execute o programa:

```bash
python organizador.py
```

> O programa copia os arquivos e mantém os arquivos originais na pasta de origem.
